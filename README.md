# 🌟 Lamia KOUDRI - Interactive 3D Portfolio

Welcome to the source code of my personal portfolio! This project is a modern, interactive, and fully responsive 3D web portfolio built to showcase my skills, experiences, and projects in **Data Science, AI, and Software Engineering**.

## 🛠️ Built With
- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) for custom 3D carousel effects
- **Typography & Icons:** `react-type-animation`, `react-icons`
- **Language:** TypeScript

## ✨ Key Features
- **3D Interactive Carousels:** Custom-built vertical and horizontal 3D carousels for the Experience and Skills sections.
- **Dynamic Animations:** Scroll-triggered animations and fluid text typing effects.
- **Responsive Design:** Seamless experience across desktop, tablet, and mobile devices with a sleek mobile navigation menu.
- **Glassmorphism UI:** Modern styling with backdrop blurs, clean gradients, and subtle glow effects.

## 🚀 Running the Project Locally

First, clone the repository:
```bash
git clone https://github.com/Lxmokdr/Lxmokdr-main.git
cd Lxmokdr-main
```

Install the dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the outcome.
